## 1 目的

验证 D-32 A 的诊断边界：

1. 只允许白名单属性离开客户端（`stage/taskType/errorCode/httpStatus/provider/model/bytes/count/unit/version/cacheHit`）；
2. 正文、笔记、证据、令牌、完整路径等字段被丢弃；
3. 诊断包文本可被泄漏扫描器检查（路径、Bearer、token=、body= 等）；
4. 事件保留关联 ID 以便定位责任单元。

## 5 边界

- 诊断包为文本格式（`schemaVersion/generatedAt/eventCount/event=...`），不是最终 UI 导出格式；
- 扫描器是模式匹配，不是完整隐私审计；
- 未验证 WER 转储、日志文件、网络遥测与保留期。

## 6 结论

- **原始事实（F）**：白名单外属性全部被丢弃；包文本通过扫描；注入的路径/令牌能被检出；关联 ID 保留。
- **项目组解释（I）**：D-32 A 的「内容无关 + 用户主动导出」可以在共享核心落地；UI 只需提供预览/裁剪入口。
- **技术/需求结论（C）**：W-E11 的规则层成立；ADR-032 仍 Proposed，缺真实日志/WER 扫描与 UI 导出。
