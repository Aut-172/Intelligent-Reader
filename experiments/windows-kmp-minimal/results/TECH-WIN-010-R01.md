# W-E12 测试报告：文档处理耗时（Windows，三类样本）

- 实验编号：W-E12（结果编号 `TECH-WIN-010-R01`）
- 关联决策：D-33 B（按文本型 / 复杂版式 / 扫描 PDF 分级预算）
- 关联 ADR：ADR-033
- 执行人：B
- 日期：2026-11-18
- 状态：**部分完成**——三类样本的单页渲染与合同生成耗时已测（3 次/样本，预热后）；内存、20 份文档、双端对照未测

## 1 目的

记录 Windows 端在固定样本上的「打开/渲染 + 合同生成」耗时分布，为 D-33 B 的分级预算提供候选观测；不形成 SLA。

## 2 环境

| 项 | 值 |
|---|---|
| 主机/系统 | HYC-1 / Build 26300.9974，单屏 150%，x64 |
| JDK/Gradle/Kotlin | 21.0.12.1 / 8.14.7 / 2.1.20 |
| 组件 | Apache PDFBox 3.0.5 |
| 样本 | SELF-001 文本、SELF-002 双栏、SELF-003 表格/公式、SELF-004 扫描 |
| 运行方式 | 每样本 1 次预热 + 3 次测量；`-Xmx2g`；冷启动 JVM |
| 原始数据 | `docProbe/results/we12-perf.tsv` |

## 3 结果（毫秒）

| 样本 | 类型 | 渲染 p50 / max | 合同生成 p50 / max | 说明 |
|---|---|---|---:|---|
| SELF-001 | 文本型单栏 | 11 / 12 | **17 / 24** | 1 页 276 字符 |
| SELF-002 | 复杂版式双栏 | 12 / 14 | **22 / 22** | 2 页 539 字符 |
| SELF-003 | 表格/公式 | 8 / 9 | **12 / 13** | 1 页 270 字符 |
| SELF-004 | 扫描件（无文本层） | **116 / 175** | 117 / 177 | 2 页；渲染主导，文本为 0 |

- 「合同生成」含文件读取、PDFBox 解析、行级文本位置收集；不含 UI、索引、OCR、网络。
- 扫描件的耗时主要来自页面渲染（72 dpi），不是文本抽取。

## 4 判定（对照 W-E12 通过证据）

| 通过证据 | 是否取得 | 说明 |
|---|---|---|
| 三类文档分别记录 | ✅ | 文本/复杂/扫描各 1 个样本 |
| 多次测量与分布 | ✅（3 次/样本） | p50 与 max 已给出；样本量小 |
| 内存/磁盘/CPU | ⚠️ 部分 | 已补 RSS 采样（§7）：app-image 峰值 7.9 MB、PDF 渲染 123.7 MB；短进程采样可能低估 |
| 20 份文档预算 | ❌ | 未做批量 |
| 双端对照 | ❌ | 需 Android 同口径 |
| 正式阈值 | ❌ | 需更多样本与 D-33 批准，候选 10/30/60 秒不作 SLA |

## 5 边界与风险

1. 单机、单 JVM、固定样本，不能让渡为整体性能结论；
2. 未包含索引构建、OCR、UI 渲染、网络与模型调用；
3. 堆增量噪声大（GC 回收导致负值），本轮不报告内存数据；
4. 扫描件的 116–175 ms 只是渲染耗时，OCR 成本属 W-E03（本轮跳过）。

## 6 结论

- **原始事实（F）**：三类样本的合同生成 p50 为 12–22 ms，扫描件渲染 p50 116 ms；重复测量波动小（除扫描件首轮 175 ms）。RSS 采样：app-image smoke 峰值 7.9 MB、PDF 渲染 123.7 MB。
- **项目组解释（I）**：在 2 GB 堆、桌面 CPU 条件下，PDFBox 的解析与单页渲染成本较低，足以支撑后续 UI 与索引实验；扫描件的主要成本是渲染而非文本。
- **技术/需求结论（C）**：W-E12 取得「三类分级」的初步数值与初步 RSS，但缺批量与双端数据，不能形成正式阈值；ADR-033 仍 Proposed。

## 7 内存补充（RSS 采样，2026-11-18）

| 进程 | 场景 | 峰值工作集 | 耗时 |
|---|---|---|---|
| `ReaderWinProbe.exe`（app-image） | 17 项 smoke | **7.9 MB** | 566 ms |
| `java.exe`（PDFBox 200 dpi 渲染） | A4 单页 → PNG 1653×2338 | **123.7 MB** | 535 ms |

- 方法：`Start-Process` 启动后每 20 ms 采样 `PeakWorkingSet64`；结果写入 `results/we12-memory.json`。
- 限制：短进程可能低估峰值；工作集包含共享运行时页，不等于私有内存；未测 20 份批量与索引/OCR 叠加。
