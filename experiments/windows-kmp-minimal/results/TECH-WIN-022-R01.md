# W-E02 复杂文档样本合同实验

- 实验编号：W-E02 补充（结果编号 `TECH-WIN-022-R01`，承接 `TECH-WIN-005-R01`）
- 关联决策：D-22 A、D-33
- 执行人：B
- 日期：2026-11-18
- 状态：**部分通过**——CJK 字体、表格、大页通过；旋转页 bbox 失败
- 环境：本机 Windows 11，JDK 21，PDFBox 3.0.5

## 1 目的

补齐 W-E02 的复杂样本维度：CJK 字体、表格、旋转页、大页，验证统一合同（页面/文本/坐标/能力/降级）是否稳定。

## 2 方法

新增 `docProbe/.../ComplexMain.kt`，用 PDFBox 生成 5 个样本并复用合同口径抽取：

| 样本 | 内容 | 字体 |
|---|---|---|
| `CJK-SIMHEI` | 4 行中文（合同/引用/降级说明） | `simhei.ttf` |
| `CJK-SIMKAI` | 2 行中文 | `simkai.ttf` |
| `TABLE-4X4` | 4×4 表格（16 格） | `simhei.ttf` |
| `ROTATED-90` | 页面旋转 90°，一行中文 | `simhei.ttf` |
| `LARGE-A3` | A3 页面，60 行中文 | `simhei.ttf` |

输出：`docProbe/results/we02-complex.tsv`、样本 PDF 在 `docProbe/results/complex/`。

## 3 结果

| 样本 | 页 | runs | chars | bboxCoverage | rotation | 判定 |
|---|---|---|---|---|---|---|
| CJK-SIMHEI | 1 | 4 | 86 | **1.000** | 0 | ✅ |
| CJK-SIMKAI | 1 | 2 | 28 | **1.000** | 0 | ✅ |
| TABLE-4X4 | 1 | 16 | 42 | **1.000** | 0 | ✅ |
| ROTATED-90 | 1 | 1 | 22 | **0.000** | 90 | ❌ bbox 失效 |
| LARGE-A3 | 1 | 60 | 2631 | **1.000** | 0 | ✅ |
| LARGE-100P | 100 | 2000 | 84940 | **1.000** | 0 | ✅（合同 434 ms、渲染 156 ms） |

## 4 关键发现

1. **CJK 字体可嵌入并抽取**：`simhei.ttf` / `simkai.ttf` 均能生成中文 PDF，文本与 bbox 正常。
2. **表格可抽取**：16 个单元格全部产生独立 run，bbox 覆盖 1.000。
3. **大页可抽取**：A3 60 行、2631 字符，bbox 覆盖 1.000，未见截断。
4. **100 页压力样本可抽取**：2000 runs、84,940 字符、bbox 1.000；合同 434 ms、首屏渲染 156 ms、文件 35 KB。
4. **旋转页存在真实缺口**：页面 `/Rotate 90` 时文本仍可抽取（22 字符），但 `TextPosition` 的 bbox 宽/高为 0，`bboxCoverage=0.000`。当前合同**没有把页面旋转应用到坐标**，因此“高亮/回跳”在旋转页会失效。

## 5 判定

| 通过证据 | 结果 |
|---|---|
| CJK 字体文本+坐标 | ✅ |
| 表格单元格文本+坐标 | ✅ |
| 大页文本+坐标 | ✅ |
| 旋转页文本+坐标 | ❌ 文本有、bbox 无 |
| 扫描页 | 由 W-E03 覆盖 |
| RTL/复杂字形/合并单元格 | ❌ 未测 |

## 6 结论

- **原始事实（F）**：CJK 三种样本（simhei/simkai/表格）与 A3 大页的 bbox 覆盖均为 1.000；旋转 90° 页面 bbox 覆盖为 0.000。
- **项目组解释（I）**：PDFBox 对未旋转页面可稳定给出坐标；对带 `/Rotate` 的页面，`TextPosition` 坐标未随页面旋转变换，需在合同层做旋转矩阵映射或改用渲染坐标。
- **技术/需求结论（C）**：W-E02 的字体/表格/大页维度成立；旋转页坐标是**必须修复的合同缺口**，D-22 保持 Proposed。修复建议：读取 `page.rotation`，对 bbox 做 90/180/270 变换；或对旋转页走“渲染 + OCR/坐标回映”。
