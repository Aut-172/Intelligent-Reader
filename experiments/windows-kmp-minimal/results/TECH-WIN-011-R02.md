# W-E13 升级覆盖测试（第二运行）

- 实验编号：W-E13（结果编号 `TECH-WIN-011-R02`，承接 `TECH-WIN-011-R01`）
- 关联决策：D-08、D-34 A、D-35 A
- 执行人：B
- 日期：2026-11-18
- 状态：**已完成本机升级覆盖**；签名与干净虚机仍待 W-E15

## 1 目的

验证同一 `--win-upgrade-uuid` 下，1.0.1 MSI 能覆盖 1.0.0、程序可运行、卸载后无残留。

## 2 环境

| 项 | 值 |
|---|---|
| 主机/系统 | HYC-1 / Build 26300.9974 |
| JDK / WiX | 21.0.12.1 / 3.14.1.8722 |
| 制品 | `ReaderWinProbe-1.0.0.msi`、`ReaderWinProbe-1.0.1.msi`（均 72,147,500 B） |
| 安装模式 | 每用户（`--win-per-user-install`），同一 upgrade UUID |

## 3 结果

| 步骤 | 命令/动作 | 结果 |
|---|---|---|
| 安装 1.0.0 | `msiexec /i 1.0.0.msi /qn` | 退出码 0；注册项 `{631441D6-…}`，版本 **1.0.0**，路径 `%LOCALAPPDATA%\ReaderWinProbe` |
| 升级 1.0.1 | `msiexec /i 1.0.1.msi /qn` | 退出码 0；注册项变为 `{DA79E811-…}`，版本 **1.0.1**，路径不变 |
| 升级后运行 | 启动已安装 exe | **17/17 PASS** |
| 卸载 | `msiexec /x 1.0.1.msi /qn` | 退出码 0；安装目录删除；未列出残留卸载项 |

**观察**：升级后 ProductCode 改变（`631441D6…` → `DA79E811…`），安装位置不变；`--win-upgrade-uuid` 起到升级关联作用。

## 4 判定

| 通过证据 | 是否取得 | 说明 |
|---|---|---|
| 版本递增覆盖 | ✅ | 1.0.0 → 1.0.1，退出码 0 |
| 升级后启动 | ✅ | 17/17 |
| 升级后数据保留 | ⚠️ 不适用 | 当前应用不写用户数据；数据迁移需在接入存储后复测 |
| 卸载残留 | ✅（本机） | 目录与注册项均清理 |
| 签名与 SmartScreen | ❌ | 未签名 |
| 干净虚机 | ❌ | W-E15 |

## 5 结论

- **原始事实（F）**：1.0.1 覆盖 1.0.0 成功，ProductCode 更换、路径不变、程序可运行、卸载干净。
- **项目组解释（I）**：D-08 的升级路径在本机可用；`--win-upgrade-uuid` 是必需参数。
- **技术/需求结论（C）**：W-E13 的本机安装/升级/卸载闭环完成；ADR-034/035 仍 Proposed（缺签名、干净机、数据迁移）。
