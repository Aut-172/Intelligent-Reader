# W-E12 批量与首读性能补充

- 实验编号：W-E12 补充（结果编号 `TECH-WIN-023-R01`，承接 `TECH-WIN-010-R01`）
- 关联决策：D-33、D-34
- 执行人：B
- 日期：2026-11-18
- 状态：**部分通过**——20 份批量、首读/首反馈/完成、CPU/磁盘已测；双端对照缺
- 环境：本机 Windows 11，JDK 21，PDFBox 3.0.5

## 1 目的

补 W-E12 的批量、首读、首反馈、完成、CPU 与磁盘维度，验证 20 份文档预算。

## 2 方法

`docProbe/.../Perf20Main.kt` 生成 20 份 PDF（1–3 页、20/45 行、部分 A3），共 30 页；对每份测量：

- **firstReadable**：加载 + 第 1 页文本抽取；
- **firstFeedback**：第 1 页 72 dpi 渲染；
- **complete**：全文抽取；
- **CPU**：进程 CPU 时间增量；
- **磁盘**：文件大小。

首份文档先预热、不计入统计。原始数据：`docProbe/results/we12-batch.tsv`；汇总：`results/we12-batch-summary.txt`。

## 3 结果

| 指标 | p50 | p95 | max |
|---|---|---|---|
| firstReadable | **1.9 ms** | 4.7 ms | 6.0 ms |
| firstFeedback | **4.8 ms** | 38.9 ms | 77.0 ms |
| complete | **2.7 ms** | 4.5 ms | 5.3 ms |
| CPU | **62.5 ms** | 250.0 ms | — |

| 项 | 数值 |
|---|---|
| 文档数 / 页数 | 20 / 30 |
| 总大小 | 127.0 KB（合成样本，非真实文档） |
| 单份最大 | 6.8 KB |

## 5 结论

- **原始事实（F）**：20 份合成 PDF、30 页，首读 p50 1.9 ms、首反馈 p50 4.8 ms、完成 p50 2.7 ms、CPU p50 62.5 ms、总大小 127 KB。
- **项目组解释（I）**：在桌面 CPU、PDFBox 3.0.5 下，短文档的文本与首屏渲染成本很低；A3/45 行样本使首反馈 p95 升至 38.9 ms；合成样本尺寸远小于真实 PDF，磁盘数字只作下限。
- **技术/需求结论（C）**：W-E12 的批量/首读/CPU/磁盘维度成立；双端对照与正式阈值仍缺，ADR-033 保持 Proposed。
