# A-E10-R01 · Keystore 安全凭据与日志脱敏

experiment_id:  A-E10-R01
date:           2026-11-17
覆盖决策:       D-18、D-20、D-31
runtime:        Xiaomi 12S Pro (2206122SC) / Android 15 (API 35)

## 结果

| 项 | 数值 |
|---|---|
| 密钥生成 | keyCreated=true（AndroidKeyStore AES） |
| 算法 | AES |
| 加解密往返 | roundTripOk=true（AES/GCM/NoPadding） |
| 撤销/退出清理 | 按钮 8 清除 sync_queue.json、sync_cursor.txt、SAF 持久授权、Keystore 密钥后，`files/` 仅剩 profileInstalled + results |
| 备份排除 | manifest `allowBackup=false` + `fullBackupContent=false` |
| 日志脱敏 | app 源码无 `Log.*`/`System.out`/`println`（grep 为空），不产生日志 |

## 解释 (I)

Keystore 凭据密钥不进普通 SharedPreferences/数据库；撤销/退出时本地队列、游标、持久授权、Keystore 密钥均可清理；备份排除已显式关闭；App 不写日志，无正文/密钥/路径泄漏面。

## 结论 (C)

D-31 平台安全凭据基线（Keystore + 备份排除 + 日志最小化）在真机成立。

## 风险 (R)

- 硬件级密钥（isInsideSecureHardware）为隐藏 API 未测。
- 崩溃报告/遥测未接入，故「崩溃报告脱敏」未实测。
