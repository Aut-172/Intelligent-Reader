# Windows 平台事实探针

本目录是架构调研阶段角色 B 的**最小平台事实探针**，不是阅读器产品原型，也不代表任何候选路线（KMP/Compose Desktop、Rust/Tauri、Qt）已经验证。

## 1 目的

《架构调研与设计阶段四人分工方案-V1.0》要求 B 在 Windows 11 上验证已闭合决策（D-05 分别授权、D-07 最低版本、D-08 交付制品、D-10 导出）的**平台可实施性**，并区分「已有实验直接支持」与「仅有官方资料支持」。现有 Windows 实验（`experiments/parser-benchmark`、`retrieval-benchmark`、`qa-benchmark`、`minimal-chain-java`）全部集中在**库层/进程内**能力（解析、OCR、检索、门控、云端适配），没有覆盖 Windows 桌面壳层依赖的以下平台事实：

- 运行环境矩阵（系统版本、运行时、WebView2、长路径开关）；
- 路径式文件访问与「授权」的真实语义（移动/删除/只读/占用后能否继续读）；
- 高 DPI 与多显示器参数；
- 导出覆盖行为。

本探针只测量这些**平台事实**，不下载依赖、不调用云端、不安装任何软件、不改系统设置，全部读写限定在 `experiments/windows-env-probe/tmp/`（运行后自清理）。

## 2 运行

```powershell
pwsh -NoProfile -File experiments/windows-env-probe/probe_windows_env.ps1
```

- 输出：控制台摘要 + `results/TECH-WIN-001-R01.json`（机器可读原始观测）。
  若当前进程无权写工作区（例如受限代理沙箱），脚本自动回退到 `%TEMP%\reader-win-probe\` 并打印 `NOTE` 行；此时以 `results/TECH-WIN-001-R01.md` 记录的回填值为准。
- 需要 PowerShell 5.1+；不需要管理员权限。
- 只读注册表项，不写入注册表；不修改 ACL；不写系统目录。

## 3 结果编号与口径

| 编号 | 覆盖内容 |
|---|---|
| `TECH-WIN-001` | 运行环境矩阵：系统版本/构建号/架构、长路径开关、WebView2 运行时、桌面运行时（.NET/JVM/Node）存在性 |
| `TECH-WIN-002` | 文件路径身份与访问语义：移动/删除后原路径失效、只读属性、共享模式占用、覆盖写 |
| `TECH-WIN-003` | 显示与缩放：显示器数量、分辨率、系统 DPI 与缩放比例 |

每条观测记录三档口径，与项目既有实验一致：

- **原始事实（F）**：脚本直接测得的数值或异常类型；
- **项目组解释（I）**：该事实对 Windows 端架构意味着什么；
- **技术/需求结论（C）**：可写入架构文档的结论及证据等级。

## 4 边界

1. 不测量 UI 壳层（窗口、选区、渲染）性能：需要真实桌面工程，属 `D-12` 后续实验。
2. 不测量安装包/签名/升级/卸载：需要打包工具链（jpackage/WiX/NSIS），当前机器未安装 JDK/Maven，登记为 `【待测】`。
3. 不测量凭据存储写入：`Windows Credential Manager` 写入会在用户凭据集留下痕迹，本轮只登记其存在性与官方能力边界（`【官方】`）。
4. 不把本机单次结果外推为 Windows 11 全版本结论；本机版本、缩放和策略状态必须随结果登记。
5. 不修改任何系统策略（包括长路径开关、DPI 兼容性设置、Defender 受控文件夹访问）。
