## 1 目的

分工方案 P0 要求 B 首先完成「Windows 已有实验和缺失证据」的盘点。本文档：

1. 把工作区全部 Windows 侧既有实验按能力域登记为可引用证据，标明运行环境与**不能证明什么**；
2. 把调研文档中的【待测】项映射到后续 `TECH-WIN-*` 实验编号、判定标准与停止条件；
3. 记录本轮已执行的平台事实探针 `TECH-WIN-001-R01`；
4. 规定「实测 → 回填证据等级」的规则，供 A、D 交叉评审。

本文档不新增需求编号，不改变 D-00 至 D-10 结论，不作为 SLA 依据。

### 2.2 证据质量提示（须随引用一并说明）

1. **机器不一致**：部分结果记录的路径与本工作区不同（如 `TECH-ARCH-004-R01` 的 CLI 位于 `C:\Users\联想\...`、工程位于 `D:\Develop\Project\Intelligent-Reader`）。这类结果只证明「在某个 Windows 环境可运行」，不能作为本机性能、路径或依赖基线。
2. **层级不一致**：解析/OCR/检索/问答证据都在库层与进程内，没有任何一条证明「桌面窗口里能选区、能高亮、能回跳」。
3. **样本规模小**：解析 3 份自制 PDF、OCR 2 页清晰样本 + 8 张公开图片 11 问、多文档 12 份合成文档；不得外推为真实文档质量。
4. **形态不一致**：没有一条证据来自打包后的制品（无 jpackage/MSI/zip 运行记录）。
5. **决策状态**：以上均为「部分支持/设计推断」，不是正式架构结论。

## 4 本轮已执行：TECH-WIN-001-R01

- 脚本：`experiments/windows-env-probe/probe_windows_env.ps1`（15 项检查；纯 ASCII 编写，避免在中文区域或不同脚本编码下解析失败，可在任意 Windows PowerShell 5.1+ 运行）。
- 结果：`experiments/windows-env-probe/results/TECH-WIN-001-R01.md`（含逐项观测值、F/I/C 与边界）。
- 关键观测：Build 26300.9974 的 Windows 11 分支系统（`ProductName` 仍写 Windows 10，不可用于判断）；WebView2 `157.0.4341.46` 已预装；`LongPathsEnabled=1`；单显示器 150% 缩放；未提权；Credential Manager 与 DPAPI 目录存在；文件移动/删除后旧路径立即失效并抛 `FileNotFoundException`；只读属性阻断写入抛 `UnauthorizedAccessException`；独占共享模式阻断并发打开抛 `IOException`；覆盖写不留旧版本。
- 产出结论：Windows 端无持久文件授权原语；导出覆盖必须自建确认与失败处理；长任务恢复必须自建持久队列；本机缺 JDK/Maven/Rust/Node，打包验证无法进行。

1. 实测通过 → 在《Windows端架构调研与比较.md》把对应【待测】改为【W实测】并附证据编号与文件链接。

3. 仅官方资料支持的内容不得写成「已验证」；不得用 Android 结果替代 Windows 结论，也不得用库层结果替代桌面壳结论。
4. 每条 `TECH-WIN-00x-R01` 需登记：样本、设备、Windows 版本/构建、缩放/显示器、工具链版本、计量口径、停止条件与原始结果路径。
5. 若实测与 D-00 至 D-10 冲突，只登记证据、影响与重开建议，由 A 提交项目负责人，不在本文件改结论。

## 7 环境与样本声明（防「结果不可复现」）

- 环境：本机 `HYC-1`，Build 26300.9974（Windows 11 分支），x64，单显示器，150% 缩放，未提权，`LongPathsEnabled=1`，WebView2 `157.0.4341.46`；探测进程为低完整性沙箱进程（代理环境造成，不代表普通桌面应用上下文）。
- 样本：沿用项目自制固定样本 `SELF-001`（单栏）、`SELF-002`（双栏）、`SELF-003`（表格/公式）、`SELF-004`（扫描），均有 SHA-256 与人工标注；新增样本须登记来源与授权状态。
- 计量：冷启动、首屏、打开文档、首字反馈、完整回答、解析/索引 CPU 与内存峰值；分别报告 Windows 与 Android。
- 合规：样本公开或经授权；不使用未授权真实资料；日志与结果不含原文、密钥与查询内容。

## 8 与 Android 验证计划的对应关系（供 A 横向比较）

| 维度 | Android（C） | Windows（B） |
|---|---|---|
