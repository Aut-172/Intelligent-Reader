## 2 质量属性场景更新

| 条目 | 更新内容 | 状态 |
|---|---|---|
| QA-04 | 单一模型供应方超时、限流或不可用时，明确降级为本地阅读与检索 | 策略已选择，阈值待验证 |
| QA-05 | 笔记保留冲突副本；进度选最新有效记录；删除使用 tombstone，并通过操作上传与变更流传播 | 策略与协议族已选择，阈值待验证 |
| QA-07 | 通过单一供应方适配器外发最少证据，具体供应方待 D-29 | 边界已选择，供应方待决策 |
| QA-10 | KMP、文档组件、模型供应方均通过契约和适配器控制替换影响 | 实验范围已选择，最终技术待 D-28 |
| QA-12 | 云中立部署和华为云映射可从干净环境重建 | 部署方向已选择，实验未完成 |
| QA-13 | 粗粒度服务和模型适配器失败可通过脱敏关联 ID 定位 | 责任方向已选择，字段待 D-32 |
| QA-14 新增 | AI/RAG 部署单元失败时，身份同步和本地阅读不受影响 | Proposed，待故障注入 |
| QA-15 新增 | 同一部署清单映射到华为云时不改变业务和数据边界 | Proposed，待部署验证 |
| QA-16 新增 | 使用替换桩替代模型供应方时，客户端和业务契约无需变化 | Proposed，待适配器测试 |
| QA-17 新增 | 两端打开同一内容但路径和名称不同的文件时，精确哈希自动识别为同一版本；内容变化时不自动绑定 | 策略已选择，待双端样本验证 |
| QA-18 新增 | 同步请求包含超限摘录、未知字段或敏感内容进入日志路径时，服务端拒绝或裁剪并保持日志无正文 | 边界已选择，字段上限待 D-31 |
| QA-19 新增 | 设备被撤销或刷新令牌失效后再次上传，服务端在业务写入前拒绝，客户端进入重新认证或终态 | 策略与协议族已选择，错误模型待 D-27 |
| QA-20 新增 | 删除已传播后长期离线设备携带删除前 revision 重连，数据不得复活；游标过期时执行重新基线且保留未确认操作 | 策略与协议族已选择，周期待验证 |
| QA-21 新增 | 本地数据库或索引被复制到另一账号/设备上下文，应用不得把平台凭据混入普通数据文件，敏感日志保持脱敏 | 保护方向已选择，威胁验证待 D-31 |
| QA-22 新增 | 同一 SyncOperation 因网络重试或响应丢失被重复提交时，服务端返回稳定兼容结果且资源只产生一次业务效果 | Proposed，待真实事务与故障注入 |
| QA-23 新增 | 服务端提交成功但客户端未收到响应时，客户端重启后以同一 operation id 重试，不产生重复笔记、进度倒退或重复 tombstone | Proposed，待双端持久化验证 |
| QA-24 新增 | 客户端应用一批远端变更后、保存新 cursor 前崩溃，重启后允许重复拉取和幂等应用，但不得永久漏掉任何变更 | Proposed，待崩溃点测试 |
| QA-25 新增 | cursor 或 tombstone 窗口过期时服务端返回 REBASE_REQUIRED；客户端重建远端状态和 cursor，同时保留并重新校验未确认本地操作 | Proposed，保留周期待 D-19 验证 |
| QA-26 新增 | 客户端与服务端协议版本不兼容时明确拒绝或要求升级，不得猜测破坏性字段；可兼容字段保持幂等与游标语义 | Proposed，兼容周期待 D-27 |

## 3 需求来源与编号规则

1. 本增量只更新架构决策映射，不新建 FR、BR、NFR、UC 或 AC 编号。
2. 不把不同来源的同号需求自动合并；所有现有来源前缀保持不变。
3. D-11 至 D-21 是架构决策来源，不替代上游需求来源。
4. 新增 AD-15 至 AD-23 和 QA-14 至 QA-26 只属于架构分析命名空间。
5. 具体字段、阈值、实现技术和供应方仍由 D-22 至 D-35 及实验结果决定；D-19 的具体保留天数、D-21 的批次阈值和协议支持周期尚未确定。
