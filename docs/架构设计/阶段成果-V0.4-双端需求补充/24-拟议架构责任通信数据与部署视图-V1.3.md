## 1 责任视图

| 单元 | 主要责任 | 明确不负责 |
|---|---|---|
| Android 客户端 | 文件授权、成熟文档组件、OCR 适配、本地混合索引、证据选择、阅读与笔记、引用、持久任务、SyncOperation/cursor、平台安全凭据和主动诊断包 | 不上传文件本体、全文索引或向量索引；不实现 Windows 平台能力 |
| Windows 客户端 | 本地文件访问、成熟文档组件、OCR 适配、本地混合索引、证据选择、阅读与笔记、引用、持久任务、SyncOperation/cursor、平台安全凭据和主动诊断包 | 不依赖 Android URI 或后台机制；不与 Android 共享 UI |
| KMP 共享核心候选 | 领域模型、DocumentIdentity/Version、同步状态机、冲突规则、公共合同、序列化和测试向量 | 不直接访问 UI、文件、文档组件、本地数据库、安全存储、后台任务或安装系统 |
| 身份与同步单元 | 账号、设备会话、最小文档元数据、进度、笔记、冲突副本、revision、幂等、tombstone、账号变更流和 REBASE_REQUIRED | 不保存文档本体、解析结果、全文索引或向量索引 |
| AI/RAG 网关 | 校验证据包、执行限制、调用 OpenAI 候选适配器、SSE/轮询结果、取消和错误归一化 | 不读取客户端文件、不扩展同意范围、不自行检索全文 |
| 任务与审计单元 | PostgreSQL 任务领取、重试、清理、状态、内容无关审计和诊断 | 不拥有同步写入事务；不成为原文日志仓库 |
| PostgreSQL | 同步当前态、幂等结果、账号变更记录、任务表和服务端最小数据 | 不保存文件本体、客户端索引或模型输入全文 |
| OpenAI 候选服务 | 根据已授权最少证据生成 | 不获得未授权文档、全文索引或本地路径 |

## 2 文档与检索合同

1. 平台文档适配器输出统一 `DocumentPage`、`TextRange`、`NormalizedRect`、`ParserVersion`、`CapabilitySet` 和 `DegradationReason`。
2. OCR 结果必须标记来源、语言、置信度和页面范围，不与原生文本静默混合。
3. 本地索引由全文/BM25 与固定中文嵌入向量组成，索引项绑定 DocumentVersion 和解析器版本。
4. 证据对象携带版本、锚点、摘要、权限与同意证明；服务端只接收裁剪后的证据包。
5. 引用保存结构与字符锚点。版本变化或解析语义变化时默认 stale，并向用户显示原因。

## 3 通信视图

| 路径 | 协议 | 关键约束 |
|---|---|---|
| 客户端到身份与同步 | REST/JSON push/pull | HTTPS、访问令牌、设备会话、operationId、baseRevision、syncEpoch、不透明 cursor、协议版本 |
| 客户端到 AI/RAG 网关 | REST/JSON 请求，SSE 增量响应 | 请求只含授权最少证据；支持取消、超时、限流错误和轮询回退 |
| AI/RAG 网关到 OpenAI | Responses API 候选适配器 | 供应方类型不得泄漏到业务合同；日志脱敏；固定快照待正式验证 |
| worker 到 PostgreSQL | 事务与 lease | 幂等领取、可恢复状态、卡死 lease 回收、任务与业务副作用解耦 |
| 本地平台层到 KMP 核心 | 版本化端口和数据合同 | 平台句柄、URI、路径、UI 对象和 SDK 类型不得进入共享领域 |

SSE 断流后不得拼接不确定片段。客户端可以查询任务或最终结果，服务端以请求 ID 和幂等键避免重复回答。同步 cursor 失效时返回 REBASE_REQUIRED，客户端保留未确认本地操作。

## 4 数据与隐私视图

### 4.1 仅在客户端

- 文档本体、页面图像、解析结果和 OCR 结果。
- 全文/BM25 索引、向量索引和本地嵌入模型资产。
- Android URI、Windows 路径、阅读与渲染缓存。
- 未获本次模型外发同意的笔记、摘录和候选证据。

### 4.2 可进入服务端

- 账号、设备会话、最小 DocumentIdentity/Version、不可逆内容哈希和显式版本关系。
- 进度、服务端可读笔记、冲突副本和受限短摘录。
- SyncOperation、revision、幂等结果、账号变更记录、cursor、tombstone 和任务状态。
- 不含内容的日志、指标、追踪和审计字段。

### 4.3 可发送模型供应方

- 本次查询、必要指令和客户端筛选后的最少证据。
- 不发送本地全文索引、整个文档、未授权内容、平台路径或凭据。
- 供应方留存、训练使用、区域和删除政策在 D-29 正式验证前保持开放风险。

## 5 同步与任务事务

1. 客户端先原子保存业务变化与不可变 SyncOperation，再上传。
2. 服务端校验会话、权限、幂等、revision 和 tombstone。
3. 服务端在同一 PostgreSQL 事务更新资源当前态、固化幂等结果并追加账号变更记录。
4. 客户端先幂等应用变更，再保存新 cursor；崩溃后允许重复拉取但不得漏变更。
5. cursor 或保留窗口失效时返回 REBASE_REQUIRED；重建远端态时保留未确认操作。
6. 服务端任务表使用状态、attempt、nextRunAt、leaseOwner、leaseUntil、idempotencyKey 和 lastErrorClass 等内容无关字段。
7. D-21 与 D-26 不要求 Kafka、RabbitMQ 或全局事件总线。

### 华为云候选映射

| 云中立能力 | 候选映射 | 约束 |
|---|---|---|
| 计算节点或容器 | ECS 或 CCE | 不是已选正式产品；同机最小部署优先验证 |
| PostgreSQL | RDS for PostgreSQL 类能力 | 规格、备份和地域待验证 |
| 日志与指标 | LTS、监控/APM 类能力 | 不得记录内容与秘密 |
| 密钥与秘密 | DEW/KMS 类能力 | 只描述能力，不绑定业务代码 SDK |

## 8 最终冻结门槛

- Android 与 Windows 待测清单中的关键项通过。
- D-28 KMP 和 D-29 OpenAI 正式验证通过或形成批准的替代/风险接受。
- D-33 正式阈值由双端数据确定。
- D-34 决策—测试双向追踪完整。
- 干净环境部署、迁移、重启、备份恢复和降级演练通过。
- D-19 tombstone 周期及备份例外完成评审。

门槛满足前，本文件及其中所有图均保持“拟议”状态。
