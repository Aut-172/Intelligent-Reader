# Windows 端架构调研待测清单

- 版本：V1.0
- 日期：2026-11-17
- 平台基线：Windows 11
- 用途：为 D-22 至 D-35 的 Proposed ADR 提供 Windows 正式证据；不使用 Android 或桌面脚本证据替代
- 执行规则：本清单是待授权实验范围，不表示已经开展或通过

| ID | 覆盖决策 | 当前证据状态 | 必测实验 | 通过证据 | 依赖 | 停止/重新打开条件 |
|---|---|---|---|---|---|---|
| W-E01 | D-12、D-28、D-34 | 缺少 KMP 正式 Windows target | 建立真实 Windows target，消费同一 shared 领域、同步、合同和测试向量 | release-like 构建日志、共享测试、依赖图、桥接量和调试记录 | KMP Windows 工具链、批准版本 | 目标构建不稳、平台依赖污染 shared 或调试不可维护 |
| W-E02 | D-22、D-33 | 候选组件尚无正式金标 | 使用 Windows 成熟文档组件验证固定文本、双栏、旋转、字体、表格、图片和大页 PDF | 页面、文本、坐标、高亮、能力和降级对照 | 候选 Windows 组件、固定文档集 | 关键样本无法稳定满足统一合同 |
| W-E03 | D-22、D-33 | OCR 与原生文本边界未验证 | 对扫描与混合页面验证 OCR 触发、语言、置信度、取消、缓存和失败降级 | OCR 来源、准确率样本、耗时和资源数据 | Windows OCR 候选组件 | OCR 静默覆盖原生文本或资源不可接受 |
| W-E04 | D-23、D-33 | 无正式 Windows 混合检索证据 | 运行本地全文/BM25 与固定中文嵌入，测试关键词、同义问法、增量、删除和损坏恢复 | 金标、召回/排序指标、p50/p95、内存、磁盘和安装体积 | 嵌入模型与运行时 | 语义增益不足或资源/分发超预算 |
| W-E05 | D-24、D-29、D-31 | 最少证据外发未审计 | 验证文件权限、用户同意、重排、去重、裁剪、撤权和并发请求 | 抓包与网关记录证明只外发授权证据 | 测试网关、可控同意场景 | 未授权内容进入网络、日志或缓存 |
| W-E06 | D-25 | Windows 回跳和 stale 未验证 | 测试插页、删页、重排、OCR 变化、解析器升级与新版本 | 双锚点回跳；跨版本明确 stale；无静默迁移 | W-E02/W-E03 | 引用错误落点或 stale 未显示 |
| W-E07 | D-26、D-34 | 缺少 Windows 持久后台任务证据 | 使用计划任务/应用后台 worker 或批准机制验证排队、取消、崩溃、重启、重复调度和退出 | 状态迁移、恢复日志、无重复副作用 | 本地任务仓储、幂等键 | 关闭应用后任务状态丢失或重复结果 |
| W-E08 | D-27、D-29 | REST/SSE 在 Windows 代理和休眠场景未验证 | 弱网、系统代理、VPN、睡眠/唤醒、断流、取消、限流和轮询回退 | 网络日志、UI 状态、无重复片段和最终结果一致 | 测试服务、网络整形 | SSE/轮询无法跨目标网络可靠工作 |
| W-E09 | D-21、D-26、D-30 | 缺少真实 Windows 同步与 rebase | 对真实同步服务执行重复提交、响应丢失、cursor 崩溃点、删除竞争、设备撤销和 REBASE_REQUIRED | 无漏变更、无重复副作用、未确认操作保留 | PostgreSQL 测试服务、账号/设备会话 | 数据复活、队列丢失或 cursor 误用 |
| W-E10 | D-18、D-20、D-31 | Credential Manager/DPAPI 和日志边界未审计 | 验证安全凭据、用户切换、退出/撤销、备份/复制、日志和崩溃转储扫描 | 凭据不在普通数据文件；秘密、正文和完整路径扫描通过 | 签名构建、测试账号 | 令牌、密钥或内容进入普通文件/日志/转储 |
| W-E11 | D-32 | Windows 诊断包未验证 | 注入解析、同步、SSE 和模型故障，生成用户主动导出的可预览诊断包 | 关联 ID 可定位责任单元；包内无内容与秘密 | 故障注入、字段白名单 | 无法定位关键故障或诊断包泄漏 |
| W-E12 | D-33、D-34 | 候选时间与文档数量未测 | 三类 PDF 测首次可读、首反馈、完成、p50/p95、内存、磁盘、CPU 和安装体积 | 原始记录与汇总；候选 10/30/60 秒和 20 份只作对照 | W-E02 至 W-E08、固定机器 | 无法复现或资源导致系统明显失稳 |
| W-E13 | D-34、D-35 | 无正式安装/升级证据 | 在干净 Windows 11 验证签名包安装、升级、离线启动、用户切换、卸载和残留 | 安装包信息、安装/升级日志、数据生命周期记录 | 打包签名流程、干净虚机/机器 | 升级破坏数据、卸载残留越界或签名失败 |
| W-E14 | D-29 | 无正式应用 API 证据 | 通过受控网关调用 Responses API 候选快照，测试结构化输出、流式、取消、限流、引用白名单、质量和费用 | 固定证据集结果、元数据、费用与政策记录 | 正式项目账号、费用上限、W-E05/W-E08 | 模型不可用、政策不符、质量/费用超门槛 |
| W-E15 | D-34、D-35 | 无干净机器重建证明 | 在干净 Windows 11 环境重建 shared、Windows 客户端和安装包，执行关键测试 | 环境清单、构建日志、制品哈希和测试结果 | 依赖锁定、打包说明 | 隐含本地依赖、工具链漂移或不可复现 |

## 执行顺序建议

1. W-E01 建立 KMP 正式 Windows 目标和测试骨架。
2. W-E02 至 W-E06 完成文档、检索、证据与引用。
3. W-E07 至 W-E09 完成后台任务、通信与真实同步。
4. W-E10、W-E11 完成安全和诊断。
5. W-E12 至 W-E15 完成绩效、供应方、安装升级和干净机器重建。

## Windows 端未决参数

- 正式文档组件、OCR 组件与安装分发方式。
- KMP Windows 目标、互操作边界和调试链路。
- 中文嵌入模型、运行时、资产分发和融合权重。
- 后台任务宿主、重试与应用退出语义。
- SSE 在系统代理、VPN 与睡眠唤醒下的恢复策略。
- Windows 各性能等级正式阈值。
