## 1 新增架构驱动因素

| 编号 | 驱动因素 | 决策依据 | 验证重点 |
|---|---|---|---|
| AD-24 | 两端可使用不同成熟文档组件，但必须输出统一页面、坐标、能力、解析版本和降级语义 | D-22 A | 固定复杂 PDF 金标、OCR 与高亮等价性 |
| AD-25 | 全文/BM25 与固定中文嵌入模型在客户端形成混合检索；索引不得上传 | D-23 B | 召回收益、首建与增量资源、双端一致性 |
| AD-26 | 权限过滤、检索、重排和裁剪在客户端完成；网关只接收最少证据包 | D-24 A | 网络载荷、撤权竞态、越权构造 |
| AD-27 | 结构与字符锚点绑定 DocumentVersion；跨版本默认 stale | D-25 A | 版本变化、解析器升级、错误迁移防护 |
| AD-28 | 客户端与服务端异步任务均持久、可取消、幂等和可恢复；服务端使用数据库任务表 | D-26 A | 杀进程、lease、重试和重复副作用 |
| AD-29 | 身份同步使用 REST/JSON，AI 流式使用 SSE 并提供轮询回退 | D-27 A | 弱网、代理、后台、版本兼容 |
| AD-30 | KMP 只共享领域、同步、合同和测试，平台能力通过端口隔离 | D-28 A | 双端正式构建、桥接量和测试复用 |
| AD-31 | OpenAI Responses API 与固定模型快照通过 ModelAdapter 隔离 | D-29 A | 正式 API、政策、质量、费用和限流 |
| AD-32 | PostgreSQL 统一承担同步事务、幂等、账号变更流和任务表 | D-30 A | 原子性、表增长、锁竞争和恢复 |
| AD-33 | TLS、基础设施静态加密、密钥管理、平台安全凭据和日志脱敏构成一期安全基线 | D-31 A | 威胁模型、秘密扫描、备份和日志 |
| AD-34 | 只采集内容无关结构化遥测；客户端诊断包必须由用户主动导出 | D-32 A | 可诊断性与隐私扫描同时通过 |
| AD-35 | 文本型、复杂版式和扫描文档分别设定预算 | D-33 B | 双端 p50/p95、内存、磁盘、电量和降级 |
| AD-36 | Proposed ADR 必须由风险驱动双端矩阵提供可追踪证据 | D-34 A | 决策—测试双向追踪和关键失败路径 |
| AD-37 | 三个逻辑单元允许同机部署，满足门槛后才冻结最终架构 | D-35 A | 干净环境重建、迁移、重启、备份恢复 |

## 2 新增质量属性场景

| 编号 | 属性 | 刺激与环境 | 预期响应 | 当前状态 |
|---|---|---|---|---|
| QA-27 | 文档互操作 | 同一复杂 PDF 分别在 Android 与 Windows 打开 | 关键证据回到等价页面/锚点；能力不足时显式降级 | D-22 A，待双端金标 |
| QA-28 | 检索质量与资源 | 候选 20 份文档完成首次索引并执行关键词与同义问法 | 混合检索达到批准的召回增益，资源不超过分级预算 | D-23 B；20 份仅候选测量点 |
| QA-29 | 隐私最少化 | 用户拒绝某文档外发或在请求前撤权 | 被拒绝内容不进入服务端、缓存、日志或模型请求 | D-24 A，待数据流审计 |
| QA-30 | 引用正确性 | 文档内容变化并建立新 DocumentVersion | 旧引用标记 stale，不自动迁移；可核验原版本时仍能回跳 | D-25 A，待版本样本 |
| QA-31 | 可恢复性 | 客户端或服务端任务运行中进程终止 | 重启后从持久状态恢复，不重复业务副作用，卡死 lease 可回收 | D-26 A，待故障注入 |
| QA-32 | 网络韧性 | SSE 在弱网、代理或后台切换时中断 | 明确取消或失败并轮询/重试；不重复回答或伪造引用 | D-27 A，待双端弱网 |
| QA-33 | 可移植性 | KMP 共享核心修改同步状态机或合同 | Android 与 Windows 正式目标使用同一测试向量并构建通过 | D-28 A，关闭前必须通过 |
| QA-34 | 供应方隔离 | OpenAI 超时、限流、结构化输出错误或不可用 | ModelAdapter 归一化错误并降级到本地检索；引用只来自证据白名单 | D-29 A，待正式 API |
| QA-35 | 一致性 | 数据库在同步提交或任务领取前后故障 | 当前态、幂等结果、变更记录一致；重复执行无第二次业务效果 | D-30 A，待真实 PostgreSQL |
| QA-36 | 安全与隐私 | 检查令牌、数据库备份、日志和崩溃报告 | 凭据只在安全存储；链路与静态数据受保护；日志无内容与秘密 | D-31 A，待安全验证 |
| QA-37 | 可诊断性 | 解析、同步或 AI 链路发生故障 | 以关联 ID 定位责任单元，同时诊断系统不记录内容 | D-32 A，待故障注入 |
| QA-38 | 性能 | 分别处理文本、复杂版式和扫描 PDF | 每类分别报告双端 p50/p95、内存和磁盘；候选时间不提前成为 SLA | D-33 B，待测量 |
| QA-39 | 可验证性 | 准备将任一 Proposed ADR 转 Accepted | 存在双向追踪证据，关键失败路径执行，双端结论不被单端替代 | D-34 A，矩阵待完成 |
| QA-40 | 一致性收口 | 准备发布一期最终架构与部署视图 | 需求、ADR、代码、部署和验证一致；未通过项延期或风险接受 | D-35 A，当前未冻结 |

## 3 参数与 SLA 边界

1. 10 秒可读、30 秒首反馈、60 秒完成和 20 份文档均保留为实验候选值，不写入正式 SLA。
2. D-33 关闭必须分别给出 Android 与 Windows、三类文档、p50/p95 和资源峰值。
3. D-19 tombstone 天数、D-27 协议支持周期、D-29 费用上限和 D-30 数据保留参数仍需实验或评审。
4. 新增 AD/QA 属于架构分析命名空间，不创建或合并 FR、BR、NFR、UC、AC。
