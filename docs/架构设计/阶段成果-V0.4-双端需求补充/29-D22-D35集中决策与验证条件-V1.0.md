## 2 集中实验批次

### E1 双端文档、检索与引用

- 目标：关闭 D-22、D-23、D-25 的核心正确性和资源风险。
- 环境：固定文本 PDF、复杂版式 PDF、扫描 PDF；Android 12+ 设备与 Windows 11 干净环境。
- 产出：文档能力合同对照、检索金标、stale 样本、p50/p95 与资源数据。
- 停止条件：任一端无法稳定输出最低合同，或混合检索资源明显超预算。
- 范围变化：会新增正式平台组件与模型运行时验证；需项目负责人统一授权后执行。

### E2 客户端证据、通信与模型

- 目标：关闭 D-24、D-27、D-29 的隐私、网络和供应方风险。
- 环境：可审计测试网关、弱网/代理条件、正式 OpenAI 项目账号和固定证据集。
- 产出：载荷审计、SSE/轮询报告、结构化输出与引用约束、政策和费用报告。
- 停止条件：出现未授权内容外发、无法可靠取消/回退，或供应方政策不满足。
- 范围变化：需要正式应用 API 调用；不能用 Codex 客户端体验代替。

### E3 KMP 双端共享核心

- 目标：关闭 D-28 的最终技术栈风险。
- 环境：真实 KMP shared module、Android 正式目标、Windows 正式目标、同一测试向量。
- 产出：构建日志、测试结果、桥接量、依赖图、制品与调试记录。
- 停止条件：Windows 目标无法稳定构建，平台依赖污染 shared，或复用收益不足。
- 范围变化：属于 D-12 已批准的 KMP 双端实验，不扩展到 Rust、Qt 或 Tauri Android。

### E4 同步、任务与 PostgreSQL

- 目标：关闭 D-21、D-26、D-30 的事务和恢复风险，并为 D-19 周期提供数据。
- 环境：真实 PostgreSQL、身份与同步测试服务、双端客户端、可控故障点。
- 产出：原子提交、幂等、REBASE_REQUIRED、任务 lease、备份恢复和长期离线报告。
- 停止条件：出现漏变更、重复业务副作用、删除复活或无法恢复的任务状态。
- 范围变化：需要真实最小服务端，不要求 Kafka 或 RabbitMQ。

### E5 安全、诊断、性能与部署收口

- 目标：关闭 D-31 至 D-35 的门槛。
- 环境：签名客户端、干净 Windows/Android 环境、云中立最小部署、秘密扫描和监控工具。
- 产出：威胁模型、日志/诊断扫描、三类文档性能报告、验证追踪、部署与恢复记录。
- 停止条件：内容或秘密进入遥测，正式预算不可满足，或部署不可复现。
- 范围变化：可能需要一次华为云能力映射核对；不自动确定正式云产品。

## 3 组合冲突与禁止推导

1. D-22 A 不允许把某端文档组件类型泄漏进共享核心合同。
2. D-23 B 与 D-24 A 冲突于服务端全文索引、云端向量库或服务端主动抓取本地文档。
3. D-25 A 冲突于跨版本自动迁移且不显示 stale。
4. D-26 A、D-30 A 冲突于未经容量证据直接引入 Kafka、RabbitMQ、Redis 或事件总线。
5. D-28 A 不能由现有纯 JVM/单端实验关闭。
6. D-29 A 不能由 D-15 A 或已有 Codex 使用经验自动推导为正式供应方结论。
7. D-31 A 不等于取消传输加密、静态加密、平台安全存储或备份保护。
8. D-33 B 不允许把 10/30/60 秒和 20 份文档直接写成 SLA。
9. D-35 A 在关键验证完成前只能称为拟议部署方向。

## 4 当前扩大技术验证范围的选项

- D-22 A：需要两端真实文档组件与 OCR 适配验证。
- D-23 B：需要双端中文嵌入模型运行时与索引实现验证。
- D-27 A：需要双端 SSE、后台和弱网验证。
- D-28 A：需要完成 D-12 已批准的正式 KMP 双端实验，但不扩大到其他技术路线。
- D-29 A：需要正式 OpenAI 应用 API 验证，须单独使用受控项目账号与费用上限。
- D-30 A：需要最小真实 PostgreSQL 服务端和故障注入。
- D-31 至 D-35：需要安全、诊断、性能、签名安装和干净部署证据。
