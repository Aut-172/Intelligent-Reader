# Android 端架构调研待测清单

- 版本：V1.0
- 日期：2026-11-17
- 平台基线：Android 12+
- 用途：为 D-22 至 D-35 的 Proposed ADR 提供 Android 正式证据；不替代 Windows 证据
- 执行规则：本清单是待授权实验范围，不表示已经开展或通过

| ID | 覆盖决策 | 当前证据状态 | 必测实验 | 通过证据 | 依赖 | 停止/重新打开条件 |
|---|---|---|---|---|---|---|
| A-E01 | D-12、D-28、D-34 | 现有最小工程只能证明局部 Kotlin/JVM 可行性 | 建立真实 KMP Android target，shared 承载领域、同步、合同和同源测试 | release-like 构建日志、共享测试通过、依赖图、桥接量 | JDK、Android SDK、批准的 KMP 版本 | shared 被 Android API 污染或构建不可复现 |
| A-E02 | D-22、D-33 | 尚无正式 Android 文档组件金标 | 在固定文本、双栏、旋转、字体、表格、图片和大页 PDF 上验证解析、渲染、坐标和高亮 | 样本级结果、截图、锚点对照、能力/降级记录 | 候选成熟组件、固定文档集 | 关键样本无法稳定输出最低合同 |

| A-E04 | D-23、D-33 | 无正式混合检索质量与资源证据 | 建立本地全文/BM25 与固定中文嵌入索引，执行关键词、同义问法、增量、删除和损坏恢复 | 检索金标、召回/排序指标、p50/p95、内存、磁盘、包体 | 嵌入模型与运行时、固定语料 | 语义增益不足或包体/资源超预算 |
| A-E05 | D-24、D-29、D-31 | 最少证据边界未审计 | 验证权限过滤、同意、重排、去重、裁剪、撤权和并发请求 | 抓包与服务端载荷证明只外发授权证据 | 测试网关、可控同意场景 | 任一未授权内容进入网络、日志或缓存 |
| A-E06 | D-25 | 引用锚点和 stale 未做正式版本验证 | 测试插页、删页、重排、OCR 变化、解析器升级与新 DocumentVersion | 双锚点可回跳；跨版本明确 stale；无静默迁移 | A-E02/A-E03 | stale 未显示或引用错误指向新内容 |
| A-E07 | D-26、D-34 | 仅有局部持久化证据 | 使用 WorkManager 或等价平台机制验证排队、约束、取消、杀进程、重启、重复调度和卸载 | 状态迁移、重启恢复、无重复副作用 | 本地任务仓储、幂等键 | 进程死亡后丢任务或重复业务结果 |
| A-E08 | D-27、D-29 | REST/SSE 真实 Android 网络行为未验证 | 弱网、断流、代理、后台切换、取消、限流、Retry-After 和轮询回退 | 网络日志、UI 状态、无重复片段和最终结果一致 | 测试服务、网络整形 | SSE/轮询均不能可靠完成或取消 |

| A-E12 | D-33、D-34 | 候选 10/30/60 秒与 20 文档未测 | 三类 PDF 分别测量首次可读、首反馈、完成、p50/p95、峰值内存、磁盘和电量 | 原始记录与汇总报告；候选数字仅作对照 | A-E02 至 A-E08、固定设备 | 无法稳定复现或资源导致系统杀进程 |

## 执行顺序建议

1. A-E01 建立正式 KMP Android 证据骨架。
2. A-E02 至 A-E06 完成文档、检索、证据和引用链。
3. A-E07 至 A-E09 完成任务、通信和真实同步。
4. A-E10、A-E11 完成安全与诊断。
5. A-E12 至 A-E15 完成性能、供应方、签名交付和干净重建。

## Android 端未决参数

- 正式文档组件与 OCR 组件。
- 中文嵌入模型、运行时、模型资产分发和融合权重。
- WorkManager 约束、重试和保留周期。
- SSE 重连、后台策略和轮询间隔。
- Android 各性能等级正式阈值。
