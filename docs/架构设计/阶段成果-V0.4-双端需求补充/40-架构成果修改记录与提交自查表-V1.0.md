## 2 关键口径变更与保持项

本轮没有改变 D-00 至 D-35 的方向。新增文档统一了以下表达：

1. D-11 至 D-35 方向已选，但对应 ADR 全部保持 Proposed。
2. 业务能力、逻辑模块、代码组件、进程和独立部署服务是五个不同层次。
3. 三个服务端逻辑责任单元可同机部署，不等同于固定三个独立云服务。
4. Android 证据只支持单端局部结论；Windows 正式报告仍待角色 B。
5. KMP 必须由真实 Android/Windows targets 验证，纯 Kotlin/JVM 不足以关闭。
6. Responses API、政策、质量、费用和限流必须使用正式应用 API 验证。
7. 10/30/60 秒和 20 份文档是候选测量点，不是 SLA。
8. 历史团队空间、公开分享、Flutter、macOS/iOS 图件不进入当前基线。
