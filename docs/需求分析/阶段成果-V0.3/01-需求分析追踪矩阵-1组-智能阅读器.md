## 3. 模型一致性结论

1. 文档证据链固定为 `DocumentVersion -> Page -> ContentBlock -> Evidence -> Citation -> Claim/Answer`，支撑引用核验与版本失效。
2. 单文档问答直接关联 `DocumentVersion`；多文档检索才关联用户显式选择的 `DocumentSet`，避免强制创建集合。
3. `PermissionGrant` 负责“谁可访问什么”，`Policy` 负责“何种证据可外发”，二者在检索与模型调用前共同生效。
4. `Annotation` 与 `NoteCard` 分离：前者是原文局部标记，后者可综合原文、回答和个人思考；两者均保留版本与定位关系。
5. 类方法表示分析阶段的业务职责，不作为最终接口或代码签名；下阶段接口设计仍需从时序消息和SPEC进一步细化。
