# 智能阅读器需求分析成果提交说明

## 1. 本轮定位

本目录为作业3“需求分析”第一组独立分析路线的课堂答辩准备版。分析输入仅使用第一组正式基线提交 `899957a` 中的需求调研、需求模型 V0.2、SRS V1.0、SPEC V1.0及其用例图、领域模型和关键流程图；第二组已有的作业3需求分析报告、类图、时序图和汇报材料不作为内容来源。

两个小组均参与共同的需求调研和需求建模基础工作，并在共同基线上采用不同工具、提示词和技术路线开展需求分析。本目录只呈现第一组路线，不把团队分工描述为“第一组只调研、第二组只建模”。

## 2. 课程要求的适配

课堂展示与提交要求 PDF 以“学术成果分享平台”为示例，列出的三个时序流程属于该选题。智能阅读器按本项目任务书“需求分析”条款适配为四个关键交互模型：

1. 文档导入解析；
2. 段落或选中文本问答；
3. 跨文档检索；
4. 笔记保存。

提交形式沿用课程要求：需求分析报告、核心业务类图、关键时序图、8至10页汇报PPT、修改说明与版本记录、AI使用声明和自查清单。

## 3. 编号口径

- `[V0.2] FR-01至FR-12、BR01至BR15、NFR01至NFR13`：第一组需求模型 V0.2 的编号空间，本轮追踪矩阵与模型引用的主口径。
- `[SRS-V1.0] FR-01至FR-11、BR01至BR07、NFR-01至NFR-07`：SRS V1.0 的映射视图。
- 两套文件存在同号异义和拆分/合并关系。本轮不重编号；引用需求时必须写来源前缀。

## 4. 版本与限制

- 当前版本：作业3 V0.1，日期 2026-10-27。
- 当前图件源文件为 PlantUML，可复现并通过语法检查。课程要求最终在华为 CodeArts Modeling 中建档并导出；由于当前未提供 CodeArts 项目入口和登录态，CodeArts 建档仍需提交负责人完成，不能把 PlantUML 文件冒充为 CodeArts 源文件。
- 课堂教师点评和小组互评尚未发生，版本记录表预留反馈行，不虚构反馈来源。
- 团队成员与主讲分工应在上传前由团队负责人最终确认。
