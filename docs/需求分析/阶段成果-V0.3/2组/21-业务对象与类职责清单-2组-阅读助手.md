# 业务对象与类职责清单（2 组 · 阅读助手 · 需求分析）

- 版本：RA V1.0
- 日期：2026-10-27
- 基线：需求模型 V0.3（类与关系）、V0.2（FR/BR/NFR/UC 编号）、SRS V1.0、SPEC V1.0
- 编号口径：`17-编号规则与术语表` V1.1；本文件新增 `BO-01`–`BO-20`（见 §1.2）
- 用途：任务书二(三)1「寻找系统中的业务对象」与二(三)2「属性、方法、关联/聚合/组合」的支撑件

## 1. 说明

### 1.1 识别方法

业务对象不是从类图反抄，而是用四个来源交叉核对：

| 来源 | 提供的对象 | 作用 |
|---|---|---|
| 任务书（三）二(三)1 的对象清单 | 20 类对象（用户、工作空间、成员权限……审计日志） | **完整性基准**：逐项回答「有没有、在哪」 |
| V0.2 §7 领域对象表 + V0.3 领域模型 | 23 个领域类及其属性/关联 | **结构基准**：对象落到哪个类、哪些属性 |
| V0.2 §5 用例清单 + V0.3 用例规约 | 12 个用例的主成功路径与异常路径 | **行为基准**：对象在哪个用例中被创建/修改/失效 |
| V0.3 领域模型 R-01～R-08 | 索引、策略、模型配置、通知、审计等新增类 | **增量基准**：2 组修订补入的对象 |

判定口径（六选一）：

| 判定 | 含义 |
|---|---|
| `直接` | 任务书对象 = 一个 V0.3 类，语义与粒度一致 |
| `别名` | 任务书对象由某个类的**一种类型取值**承载（如「批注」「笔记卡片」都是 `Note.type`） |
| `部分` | 有承载类，但缺关键字段/粒度/实体化，需在分析或后续阶段补 |
| `派生` | 不持久化，由其他对象按规则计算得出 |
| `缺口` | 无承载类，且一期需要 |
| `范围外` | 无承载类，一期明确不做 |

### 1.2 新增编号

`BO-01`–`BO-20` 按任务书对象清单顺序编号，**只在本文件与追踪矩阵中使用**，不进入领域模型，不与类名混用。类名一律使用 V0.3 英文 PascalCase（`17` §1.5）。

| 判定 | 条数 | 编号 |

## 3. 非直接对象的处置（G1～G8）

| 编号 | 对象 | 问题 | 处置（一期口径） | 影响 | 触发条件 |
|---|---|---|---|---|---|
| G1 | 目录节点 | 无独立类，只有 `section_path` | **派生对象**：按 `section_path` 分组生成章节树，节点含标题、层级、目标 block_id；不持久化 | 目录跳转依赖解析质量；验收以目录还原率度量（AC-04） | 若需用户自定义目录/书签，再引入 `TocNode` |
| G2 | 索引片段 | `Index` 与 `ContentBlock` 多对多，无 chunk 级对象 | 以「`Index`–`ContentBlock` 关联」作为索引条目；chunk 粒度由 `ContentBlock` 承载 | 权限过滤与召回粒度受 block 切分影响 | 若需 overlap/父子块，构件阶段增 `IndexEntry` |
| G3 | 摘要 | `Answer` 无类型字段，与问答共用 | 一期以**查询上下文**区分（摘要请求的 `Query.scope` 为整篇/章节）；**建议**增 `Answer.answer_type` 属性（属性级，不新增类、不改号） | 统计、筛选、导出无法按类型聚合 | 评审同意后在 V0.3 修订中加属性（Q-03） |
| G4 | 问答会话 | 仅 `Query` 单轮，无 Session | **一期限定单轮问答**；多轮上下文、指代消解不承诺 | 「刚才那个问题」类交互不支持 | 若一期必须多轮，需新增 `Conversation` 并改 FR-04（Q-04） |
| G5 | 标签 | `Note.tags` 为文本 | 一期按标签文本检索与展示；不提供标签改名/合并/统计 | 标签治理能力弱 | 若需标签治理，增 `Tag` 实体（Q-05） |
| G6 | 成员权限 | `PermissionGrant` 是资源级授权，无工作区成员角色对象 | 一期以 `User.role` + `PermissionGrant` 组合表达；共享工作区仍按 TBD-1 未决 | 团队角色/管理员边界不清 | TBD-1 结论为「需要共享」时补 Membership |
| G7 | 分享链接 | 未建模 | **一期不做分享**，以「导出到用户指定位置」满足任务书「分享或导出」；分享列后续 | 无对外链接、无访问时效控制 | 教师/组长要求分享时，需 `ShareLink` + 权限/时效（Q-02） |
| G8 | 提示词模板 | 运行时无对象；课程要求提示词资产清单 | 一期在**配置/文件层**版本化管理提示词与输出 Schema，答案记录 `prompt_version`（SPEC §5.1 已有字段）；不建运行时类 | 提示词与回答的关联只在日志层 | 构件设计阶段决定是否建 `PromptTemplate`（Q-06） |

> 处置原则：**能由现有类承载的，不新增类；必须新增的，先登记触发条件，不在本阶段擅自扩模型。** 这也是对 `17-编号规则与术语表` §3「不自造」的遵守。
