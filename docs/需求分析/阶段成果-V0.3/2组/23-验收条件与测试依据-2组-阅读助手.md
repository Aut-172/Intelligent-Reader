# 验收条件与测试依据（2 组 · 阅读助手 · 需求分析）

- 版本：RA V1.0
- 日期：2026-10-27
- 基线：需求模型 V0.3、SRS V1.0、SPEC V1.0、V0.3 用例规约
- 编号：`AC-01`–`AC-24`（流程与横向）、`AC-N01`–`AC-N14`（非功能）
- 用途：任务书（三）二(三)4「Word、PPT 及支撑材料」中的**验收依据**；下游测试用例与评测集的输入

## 0. 编写规则

1. **一条 AC 只判一件事**：可观察、可复现、可由第三方执行。
2. **Given/When/Then 三段式**：Given 是系统状态，When 是用户/系统动作，Then 是**可观察结果**（含状态名、错误码或界面文本）。
3. **状态名冻结**：只用术语表 §1.4 的 `queued/processing/parsed/indexed/needs_review/failed/stale/...`、`answered/local_evidence_only/refused/model_failed/citation_invalid` 等。
4. **不把 TBD 写成硬指标**：阈值未定的（NFR-07/10/11/12）写成「须记录/须有进度/须限资源」，并标注 `TBD-11`。
5. **测试依据**：优先引用 `SPEC §8` 的 5 个测试组；SPEC 未覆盖的（笔记、界面、评测集）在 §5 增补，**不假装已有**。
6. **证据边界**：n=20 问卷只作优先级输入，**不作为验收阈值来源**；性能/准确率必须由压测与标注集给出。

### 8.3 测试环境与样本声明（防「结果不可复现」）

- 环境：设备、OS、浏览器、模型服务与地区、网络条件必须在测试报告中写明；
- 样本：≥40 份，按任务书七.2 的六类格式分布；每份记录来源、授权状态、页数、语言、版面特点、预期结果；
- 评测：固定问题集与提示词版本；模型变更必须回归并记录差异；
- 数据合规：不使用未授权真实资料；演示数据脱敏；访谈录音与个人信息不随包外发。
