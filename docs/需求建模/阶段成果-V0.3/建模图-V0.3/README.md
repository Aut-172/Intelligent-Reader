# V0.3 建模图索引

## 展示用图

- `分拆用例图`：三张用例图，对应 PPT 第 3 至 5 页。
- `活动图`：三张场景活动图，对应 PPT 第 6 至 8 页。
- `时序图`：导入解析索引、逐文件外发确认、问答与引用校验。
- `状态图`：文档处理、回答生成。
- `领域与界面`：领域模型、界面导航图。

每张 PNG 均保留对应的 PlantUML 底稿（另一组新增图件），便于复现和后续修订。PPT 中使用的是同一批 PNG，图件与演示页面保持同步。

另一组最新交付包已确认 11 张图全部定稿，并附带 `出图清单-2组-阅读助手-v1.1.md`。其中 A1–A9 为新增图件，用例图 V0.3 与领域模型 V0.3 为基线修订件。
